# Advanced SQL Queries Practice

In this activity, I practiced advanced SQL concepts including JOINs, GROUP BY, aggregate functions, HAVING clauses, and subqueries. I learned how to combine data from multiple tables and analyze customer order information using different SQL techniques.

The most challenging part was understanding when to use subqueries versus JOINs and applying aggregate functions correctly with GROUP BY and HAVING clauses. This exercise helped strengthen my understanding of how SQL is used for reporting and data analysis in real-world applications.
